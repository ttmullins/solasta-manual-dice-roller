# Native multiplayer evidence

`python tests/network-native/run.py` checks the pinned pristine game assembly and executes copied original raw dice, Karmic dice, deterministic state restore/record, and replicated hit-die command IL. Unity's external random API is a managed boundary double. Different local Unity random draws cannot change the stored per-game random results. Each accepted manual face must advance the original native random stream once; advantage and disadvantage advance it twice, and D1 advances it zero times.

The genuine scheduler process compiles production `NativeNetworkScheduler.cs` against the original game and Unity assemblies, executes original `TA.Coroutine.Run`, and verifies owner gating, first admission inside an already running coroutine, completion of a popped iterator, failure holds, room departure, foreign patch rejection, and clean reload. The complete five-target production installer encounters unavailable Unity InternalCalls on the Linux CoreCLR host. A separate qualification process changes those Unity dependency methods to throwing managed methods, which are never invoked, and exercises the complete installer and rollback. The main game assembly remains byte identical. None of these dependency changes are part of the mod.

`python tests/network-native/runtime/run.py` executes production `RuntimeRolls`, `RollBroker`, `NativeScratchScope`, and `NativeNetworkScheduler` against original native actor dice, raw dice, Karmic dice, deterministic random state, and coroutine IL. Network transport and descriptor consensus are explicit boundary doubles. Cases cover accepted advantage pairs, manual Lucky replacements, static spell pools, shared automatic decisions, exact native random draw counts, completion gating, retained native return/output values, exact luck float bits and critical counters, randomness settings, unrelated random calls, cursor randomness, changed native arguments, cancellation, room departure, and the completion watchdog. The return/outcome/delta observation case surrounds an original native actor draw with a small wrapper boundary; original stock wrapper and observation-injection behavior are tested by the native await suite.

The pure network protocol and pinned Photon adapter have their own suites. These tests execute no live Photon session and do not certify Windows Unity/Mono, real network latency, host migration, or two-player gameplay. Those require the bundled multiplayer acceptance checklist.
