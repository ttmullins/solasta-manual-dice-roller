# Production adapter over pristine native dice IL

Run from the workspace root:

```sh
python3 work/standalone-hardening/tests/native/run.py
```

Optional input paths: `--dotnet`, `--managed`, `--cecil`. The runner compiles a private game ABI, copies the actual pristine native implementations of actor RollDie, RerollDieAsNeeded, RollDiceAndSum, raw RollDie and static RollStaticDiceAndSum, ComputeAdvantage and the native Monster substitute getters/feature enumeration and native RollMagicalHitPointsPool, then compiles the current production RollBroker.cs, RuntimeRolls.cs and NativeScratchScope.cs against it. Real Harmony installs the production prefixes, finalizers and raw-call transpilers. It does not use a Harmony stub or an invented trait processor.

The test host replaces only UI/plugin settings and effect/rest/save preparation modules. Dice-group descriptors are supplied explicitly by that host. Consequently these checks do not prove the production effect descriptor, save planner, rest planner or original native coroutine await insertion; those require their separate integration tests. The skipped-form test models which form is skipped, then invokes actual native sum calls under the production form identity. It does not run full InflictDamage/ApplyEffectForms.

The latest run passes 308 assertions. Sixty independent comparisons execute pristine native actor logic first with native RNG inputs, then with the same raw face stream accepted by the production adapter. They cover original face extremes, advantage/disadvantage, proficiency, matching and nonmatching skills, composite min/max clamps, Halfling Lucky, repeated feature rerolls, forced faces and native notification order. Further tests cover nested callback draws, unprepared native raw/bonus calls, exact batch-count guards, cancellation, accepted-array mutation, feature changes during a prompt, pending reset/disposal, skipped form identity, empty/constant rolls, disabled rerolls and native forced-critical counters.

Atomic Auto-step regressions accept the first damage group's face before canceling the second group, then execute both actual native sums and require two fresh native draws. A separate Lucky regression accepts the initial one before canceling its replacement prompt; the actual native actor redraws its original one and replacement seventeen, draws native RNG twice, and emits exactly one original native Lucky notification. Neither case applies earlier accepted values or reopens the modal during automatic native processing. Group/form preparation is supplied by the explicit fixture producer, while cancellation and face consumption execute the production adapter and native dice bodies.

Orphan-modal regressions separately advance Collect, CollectGroup and Ask. They cancel the owner or dispose only Collect while leaving its pending nested Ask untouched, then require immediate closure and rejection of stale callbacks. A later Ask cleanup cannot close a new reference-owned prompt, and canceling a plan waiting behind another visible prompt cannot close a window it never displayed. This UI host implements reference ownership, matching production Close(expected); it still supplies input without Unity rendering. The separate native await fixture proves that patched actual TA.Reset cancels/disposes its owned waiter. The dedicated `../await/integration` fixture now executes actual TA.Run/Reset and the original Jump iterator through production NativePatches, RuntimeRolls, broker and actual RollWindow ownership. That fixture uses an explicit location-ability descriptor bridge; `../ability-native` separately tests the actual native ability producer.

`results.txt` contains the runtime result; `extracted-methods.txt` identifies the copied native methods/instruction counts. `source-manifest.json` records the exact production source snapshots and pristine/Harmony hashes tested. Build/compiler artifacts are private under `build/`.

Runtime is .NET8/Linux with the real .NET8 Harmony build. The fixture-only HarmonyFixtureHost forwards actual MonoMod platform operations and supplies loaded-module filenames from `/proc/self/maps` because this container's Process.Modules is empty. That host shim is not production code and must not be packaged. These results establish native dice/control equivalence in this fixture; they do not certify Unity's Mono, Windows, UMM load order, inlining behavior, a live game or multiplayer. No GoDice code is present.

Hardening checks also cover mutable feature decisions during native reroll notifications, nulling the unused ValidSkills list during a reroll, aborting during a notification, native WildShape ownership and original-hero scratch-reference/enumerator preservation. Oversized reroll counts and aggregate plans fall back before UI; rejected native-state validators atomically retire all accepted static bonus and actor faces. The injected callback mutations are explicit fixture triggers, not a demonstrated stock asset bug.

Pending category changes close the owned modal, reject its old callback and restore native automatic rolling; reenabling permits an independent request. Exact original RollMagicalHitPointsPool tests verify SpellPools=false cannot borrow HitDice=true for either pending or already accepted Sleep-style pools. The original callback receives the fresh complete pool exactly once.
